# Matrix — библиотека матричных операций на языке C

Библиотека **s21\_matrix** реализует основные операции с матрицами на языке C стандарта C11.

## Описание

Библиотека предоставляет функционал для создания и работы с матрицами:

* `s21_create_matrix` — создание матрицы заданного размера
* `s21_remove_matrix` — очистка и уничтожение матрицы
* `s21_eq_matrix` — сравнение матриц
* `s21_sum_matrix` — сложение матриц
* `s21_sub_matrix` — вычитание матриц
* `s21_mult_matrix` — умножение матриц
* `s21_mult_number` — умножение матрицы на число
* `s21_transpose` — транспонирование матрицы
* `s21_determinant` — вычисление определителя матрицы
* `s21_calc_complements` — вычисление матрицы алгебраических дополнений
* `s21_inverse_matrix` — вычисление обратной матрицы

Матрица реализована в виде структуры с динамическим выделением памяти под элементы.

## Требования

* **Язык:** C11
* **Компилятор:** gcc
* **Стандарт:** POSIX.1-2017
* **Стиль кодирования:** Google C++ Style (адаптированный для C)
* **Библиотека:** статическая библиотека `s21_matrix.a` с заголовочным файлом `s21_matrix.h`
* **Точность вычислений:** до 6 знаков после запятой
* **Парадигма программирования:** структурное программирование
* **Ограничения:** устаревшие конструкции и функции не применяются

## Использование

Пример использования библиотеки в коде:

```c
#include "s21_matrix.h"

int main() {
    matrix_t A, B, result;

    s21_create_matrix(3, 3, &A);
    s21_create_matrix(3, 3, &B);

    // Инициализация матриц значениями

    s21_sum_matrix(&A, &B, &result);

    // Использование result

    s21_remove_matrix(&A);
    s21_remove_matrix(&B);
    s21_remove_matrix(&result);

    return 0;
}
```

## Структура матрицы

```c
typedef struct matrix_struct {
    double **matrix;    // Указатель на массив указателей на строки матрицы
    int rows;          // Количество строк
    int columns;       // Количество столбцов
} matrix_t;
```

## Коды возврата

* `0` — успешное выполнение операции
* `1` — некорректная матрица
* `2` — ошибка в вычислениях
